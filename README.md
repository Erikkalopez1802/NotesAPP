# Libreta

App de notas para tablets, al estilo FreeNotes:

- Escribes con el lápiz sobre una hoja rayada.
- La letra se convierte a una fuente.
- Puedes buscar fotos y arrastrarlas a la nota, o abrir Google Imágenes y soltarlas en la hoja.

## Cómo abrirla

Sirve la carpeta en un navegador (Chrome o Edge). En tablet, añade la página a la pantalla de inicio para usarla a pantalla completa.

El reconocimiento de letra funciona mejor si escribes grande y claro. En Chrome/Edge puede usarse el reconocimiento de escritura del sistema; si no está, usa Tesseract en el navegador.
